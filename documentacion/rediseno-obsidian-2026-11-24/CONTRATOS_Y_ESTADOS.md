# Contratos y estados

| EXISTE Y SE CONSERVA | MEJORAR PRESENTACIÓN | REQUIERE BACKEND |
|---|---|---|
| API paginada, agregados completos, 409, RBAC y cuotas | Shell, navegación, dashboard, formularios y estados | Ningún cambio API para el rediseño |
| Capturas validadas y snapshots de 30 días | Comparador local por slots, error y fallback | Comparador no requiere tabla nueva |
| Diez calculadoras, riesgo y estadística | Gráficos accesibles y tarjetas | Cotizaciones/equity real no integrados |
| Catálogo vacío, scripts cifrados, frases e importación/exportación | Bibliotecas, editores y reportes | Check-in emocional independiente: prototipo sin guardar |
| Estrategias/versiones y cuentas/fondeo | Fichas, reglas y revisiones | Plantillas personalizadas sincronizadas: pendiente, no operativas |

La demo tiene estado local aislado, solo datos ficticios y ningún acceso a APIs productivas. El producto conserva sus contratos y validaciones.
